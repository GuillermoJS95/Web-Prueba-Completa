# Juegos GJS

Tienda de videojuegos hecha con HTML y CSS para la asignatura de Multimedia II (2º DAW).

**Web:** https://webpractica3.vercel.app/

## Páginas
- `index.html`: inicio, con vídeo de presentación y botón de música.
- `tienda.html`: listado de juegos con buscador y filtros.
- `juego-pubg-mobile.html`: ficha de un juego.

## Estructura
```
index.html, tienda.html, juego-pubg-mobile.html
styles.css      estilos y diseño responsive (media queries a 900 px y 600 px)
music.js        botón de música (altavoz)
ambient.js      resplandor del vídeo de introducción
img/            portadas, hero y logo
media/          vídeo de presentación (MP4 y WebM) y música (MP3)
```
